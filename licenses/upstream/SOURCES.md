# Supplementary upstream notices

`Tcl-license.terms` is the unchanged notice from the Tcl 8.6.12 source tag:
https://raw.githubusercontent.com/tcltk/tcl/core-8-6-12/license.terms

The build uses this notice only as a fallback when the Python installation omits Tcl's `license.terms`. Python and Tk notices are collected from the installed runtime. Dependency notices are collected from the exact installed Python distributions.

The SoundFile 0.14.0 release points to its precompiled libsndfile build repository at commit `a3e6f97`:
https://github.com/bastibe/python-soundfile/tree/0.14.0

Upstream libsndfile 1.2.2 source and build instructions:
https://github.com/libsndfile/libsndfile/tree/1.2.2

Additional codec copyright and source links are supplied by SoundFile in `licensing/license_notes.md`, copied into the Windows package's `licenses/soundfile/` directory.
